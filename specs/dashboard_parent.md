# Spécifications — Dashboard Parent

Le tableau de bord parent permet de suivre les demandes de cours, de gérer les favoris et de communiquer avec les enseignants sélectionnés.

## 1. Suivi des Demandes

- **Mes demandes** : Liste des demandes envoyées aux enseignants.
- **Statuts** : Visibilité claire sur l'état (En attente / Accepté / Décliné).
- **Détails** : Rappel du besoin (matière, créneaux) pour chaque demande.

## 2. Messagerie & Contact

- Accès aux conversations ouvertes avec les enseignants ayant accepté une mise en relation.
- Notifications de nouveaux messages.

## 3. Favoris & Recherche

- **Ma Sélection** : Liste des profils d'enseignants mis en favoris pour une consultation ultérieure.
- **Accès Rapide** : Bouton pour relancer une recherche basée sur les critères précédents.

## 4. Évaluations

- **Laisser un avis** : Formulaire accessible une fois qu'une mise en relation est confirmée.
- Historique des avis déjà postés.

## 5. Paramètres du Compte

- Informations personnelles (Nom, Ville, Contact).
- Gestion des préférences de notification.
