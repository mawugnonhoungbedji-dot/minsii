# Spécifications — Dashboard Administrateur

Le tableau de bord administrateur est l'outil de pilotage, de vérification et de modération de la plateforme EduConnect.

## 1. Validation des Enseignants (Vérification)

- **File de Modération** : Liste prioritaire des nouveaux profils soumis.
- **Interface d'Examen** :
  - Visualisation des documents (Diplômes, ID).
  - Vérification de la cohérence des informations.
- **Actions** :
  - Boutons Approuver / Rejeter / Demander Correction.
  - Champ de message personnalisé pour les feedbacks.

## 2. Statistiques Globales (Analytics)

- **Utilisateurs** : Graphiques de croissance (Enseignants, Parents, Directeurs).
- **Activité** : Nombre de mises en relation par période.
- **Top Matières** : Classement des matières les plus recherchées.

## 3. Gestion des Utilisateurs

- Moteur de recherche global pour trouver un compte par email ou nom.
- **Actions de Maintenance** :
  - Suspension temporaire de compte.
  - Suppression définitive.
  - Réinitialisation manuelle si nécessaire.

## 4. Modération du Contenu

- **Gestion des Avis** : File des nouveaux avis postés.
- **Signalements** : Centralisation des contenus rapportés par les utilisateurs (profils fictifs, messages inappropriés, avis malveillants).
- **Logs** : Historique des actions effectuées par l'administrateur.

## 5. Configuration Plateforme

- Gestion des catégories de matières et des niveaux scolaires.
- Paramètres de maintenance du site.
